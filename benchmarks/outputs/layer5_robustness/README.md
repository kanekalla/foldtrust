## Files

### Core Results

- **`robustness_summary.csv`** — All cases × all conditions × all metrics. Columns:
  - `case`: Case name (cftr-5utr, hcv-ires-dii, mapt-e10, sars2-fse, smn2-iss-n1)
  - `condition`: Condition identifier (param_*, temp_*, jitter_*)
  - `tier_agreement`: Fraction of nucleotides with unchanged tier (0–1)
  - `mea_jaccard`: Jaccard index of MEA structure base pairs (0–1)
  - `mfe_jaccard`: Jaccard index of MFE structure base pairs (0–1)
  - `unpaired_spearman`: Spearman correlation of unpaired probabilities (-1 to 1)
  - `firm_retention`: Fraction of baseline FIRM pairs that remain FIRM (0–1)
  - `floppy_retention`: Fraction of baseline FLOPPY pairs that remain FLOPPY (0–1)
  - `mfe_energy`: MFE energy in kcal/mol

- **`robustness_detailed.json`** — Full per-case results including baseline metrics and all condition metrics. Use for programmatic analysis.

- **`mfe_energies_by_params.csv`** — MFE energy per case per parameter set (Turner2004, Andronescu2007, Langdon2018). Verifies parameter loading works correctly.

- **`region_stability.csv`** — Per-case mean and standard deviation of tier agreement across all conditions. Identifies most/least stable cases.

### Figures

- **`layer5_tier_agreement_heatmap.png`** — Cases (rows) × conditions (columns) heatmap of per-nucleotide tier agreement. Green = stable (agreement ≈ 1), red = unstable.

## Key Results

**Temperature is most robust:** Tier agreement 84%, MEA Jaccard 91%, unpaired Spearman 99%. Physiological temperature variations produce consistent tier classifications.

**Parameter sets show moderate divergence:** Tier agreement 63%, but FLOPPY pairs remain FLOPPY (99.8% retention). Low-confidence regions are consistently low.

**Window jitter has largest impact:** MEA Jaccard 22%, FIRM retention 28%. Window boundaries dramatically affect structure predictions.

**Most stable case:** SMN2 ISS-N1 (tier agreement 75%)  
**Least stable case:** SARS-CoV-2 FSE (tier agreement 63%, pseudoknot region)
